# SECCON Beginners CTF 2026で学ぶリバースエンジニアリング入門

ID と PASS を入力してログインすると、SECCON Beginners CTF 2026 のページへ移動するシンプルな学習用Webサイトです。

## 使い方

1. `index.html` をブラウザで開く
2. ID と PASS を入力する
3. `ログイン` ボタンを押す
4. SECCON Beginners CTF 2026 のページへ移動する

## ファイル構成

- `index.html`: ログイン画面
- `styles.css`: 画面デザイン
- `script.js`: 入力確認とページ遷移
